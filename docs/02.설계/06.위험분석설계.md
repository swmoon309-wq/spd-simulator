# 위험 분석 설계 (3차: Monte Carlo·민감도)

기능 목록 RSK-01~06, 사용 시나리오 SC-07의 설계. 입력 불확실성을 분포로 두고 모델을 반복 실행해 일정·비용·품질의 **분포와 목표 달성 확률**을 구한다. 모델 검증(VAL)은 [07.모델검증설계.md](07.모델검증설계.md)에서 다룬다.

- 근거: 책 2.8.2 민감도 분석, 2.8.3 Monte Carlo 분석, 부록 A(A.1 위험 분석과 확률, A.2.3 분포, A.3 Monte Carlo와 역변환, A.5 실험 설계, A.6 출력 분석과 신뢰구간). 표시는 05번 문서와 같다. **[책]** 책에 명시, **[표준 통계]** 책에는 없지만 널리 쓰는 통계 방법, **[설계]** 이 문서에서 정함.
- 구현 상태 기준일: 2차 완료 시점. 코드 이름은 현재 저장소의 것을 쓴다.

## 0. 먼저 읽을 것: 이 분석의 신뢰 수준

- Monte Carlo의 출력 분포는 **입력 분포의 가정**에서 나온다. 입력 분포는 사용자가 정하는 판단이며 모델이 정해 주지 않는다. 책도 "점 추정은 항상 신뢰 수준과 함께 말해야 한다"고 하고, 정보가 없으면 50% 신뢰 수준으로 읽으라고 한다(A.1).
- 통합 프로젝트 모델은 책과 **정량 일치하지 않고 보정되지 않았다**(03번 문서 0장). 따라서 "목표 일정 내 완료 확률 63%"는 **실제 프로젝트의 확률이 아니라 이 모델과 이 입력 분포에서의 값**이다. 화면은 이 안내를 결과 옆에 상시 표시하고, 시나리오 간 **상대 비교**를 먼저 권한다(책 2.8.1: 상대 결과만으로 정책 결정이 충분한 경우가 많다).
- 모델 자체가 난수를 쓰지 않으므로(현재 두 모델 모두 결정적) 출력의 변동은 전부 입력 분포에서 온다.

## 2. 입력 분포 (RSK-01)

### 2.1 분포 4종

책 A.2.3이 소프트웨어 프로세스에 쓸 만하다고 소개한 분포 중 단순한 것부터 고른다. 균등은 "범위만 안다", 삼각은 "최소·최빈·최대만 안다"(책: 데이터가 없을 때의 거친 모델), PERT는 삼각을 둥글게 만든 베타 분포(책: 최소·최빈·최대, 보통 5%·95% 분위수), 정규는 대칭 종 모양이다.

| 분포 | 입력 | 표본 추출 | 비고 |
|---|---|---|---|
| 균등 | 최소, 최대 | `x = a + r(b − a)` | |
| 삼각 | 최소, 최빈, 최대 | 역변환(닫힌 식) | 비대칭 가능. 엔진의 `RANDOM_TRIANGULAR`와 같은 식 |
| PERT | 최소, 최빈, 최대 | 역변환: 베타(α = 1 + 4(m−a)/(b−a), β = 1 + 4(b−m)/(b−a))의 역누적분포를 수치로 구해 `[a, b]`에 사상 | 평균 (a + 4m + b)/6. 역누적은 이분법과 정규화 불완전 베타 함수 [표준 통계] |
| 정규 | 평균, 표준편차, (절단 범위) | 역변환: `x = μ + σ·Φ⁻¹(r)`. 절단하면 `r`을 `[F(lo), F(hi)]`로 사상한 뒤 역변환 | 기본 절단 범위 = 그 파라미터의 허용 범위 |

로그정규·감마·경험분포(A.2.3.5~7)는 후속이다. 로그정규는 양수이고 오른쪽으로 긴 꼬리(일정·공수 추정 오차에 흔함)라서 가장 먼저 추가할 후보이다.

### 2.2 모든 분포는 균등난수 하나를 받는다

책 A.3.1의 **역변환**(`x = F⁻¹(r)`)만 쓴다. 파라미터 하나가 **균등난수 하나**를 소비하므로 분포를 바꿔도 같은 `r`로 비교할 수 있고(분위수 대응), 순위상관과 시나리오 간 공통난수(5.3)가 성립한다. 난수열이 가변인 방법(기각법, 감마 합성)은 쓰지 않는다. 책의 예제로 구현을 검증한다: 정규 N(50, 10²)에서 r = 0.42 → 약 48, r = 0.86 → 약 61, r = 0.321 → 45.4(책 그림 A.16, 표 A.3).

### 2.3 파라미터에 거는 제약

| 제약 | 규칙 |
|---|---|
| 허용 범위 | 분포의 지지구간(균등·삼각·PERT의 최소~최대, 정규의 절단 범위)이 파라미터 폼의 허용 범위 안이어야 한다. 벗어나면 입력 오류(실행을 막는다). 정규는 절단 범위를 허용 범위로 기본 설정한다. |
| 정수 | 정수 파라미터(`extra_people` 등)는 표본을 반올림한다. 결과 분포가 이산이 됨을 필드 옆에 표시한다. |
| 분포 안의 상호 제약 | 최소 ≤ 최빈 ≤ 최대, 표준편차 > 0, 최소 < 최대. 최소 = 최대(퇴화)는 허용하고 고정값으로 취급한다(시험에서 결정적 실행과 비트 동일해야 한다). |
| 독립 | 파라미터끼리 **독립**으로 추출한다(A.3.2.1과 같음). 상관은 지원하지 않는다. 같은 성격의 파라미터(예: 숙련·신입 생산성)를 따로 흔들면 현실에 없는 조합이 나올 수 있음을 안내한다. |

### 2.4 분포를 쉽게 정하기

불확실한 파라미터를 하나씩 정하는 입력이 부담이라, 파라미터를 고르면 **템플릿**을 제안한다. 기본 설정 값 `v`에서 삼각(0.8v, v, 1.3v)(추정은 낙관적으로 빗나가는 경향이 있어 위쪽을 더 넓게. [설계], 사용자가 바꾼다). 허용 범위를 넘으면 범위로 자른다. 템플릿은 출발점일 뿐이며 화면에 "가정"으로 표시한다.

## 3. 표본 추출과 재현성

### 3.1 반복·파라미터별 독립 난수열

`r(i, p) = Rng(mix(시드, i, 파라미터 이름)).next()` — 반복 `i`와 파라미터 이름마다 **독립적으로 유도한 난수열의 첫 값**을 쓴다. `mix`는 32비트 해시(FNV-1a와 정수 혼합)이다. 얻는 성질:

| 성질 | 이유 |
|---|---|
| 같은 시드·입력이면 같은 결과(NFR-05) | 결정적 |
| 반복 수를 늘려도 앞의 결과가 그대로 | `i`번째 표본이 다른 반복에 의존하지 않는다(처음 500회 = 1000회 실행의 처음 500회) |
| 파라미터를 추가·삭제해도 나머지 파라미터의 표본이 그대로 | 이름으로 난수열을 유도한다 |
| 취소해도 그때까지의 표본이 완전한 결과 | 반복이 독립 |
| 반복을 어떤 순서·병렬로 돌려도 같은 결과 | 위와 같은 이유(후속의 다중 Worker 대비) |

모델이 난수 함수를 쓰면 모델의 시드도 `mix(시드, i, '@model')`로 반복마다 유도한다.

### 3.2 층화 표집(후속)

단순 무작위 대신 라틴 하이퍼큐브를 쓰면 같은 반복 수에서 분산이 줄지만 책은 단순 방식만 설명하고, 반복 수 늘리기(최대 5,000회, 한 번에 수 초)로 충분하다. 후속 옵션으로만 둔다.

## 4. 실행 (RSK-02)

### 4.1 반복 실행

각 반복: 표본 추출 → 대상 시나리오의 유효 파라미터에 덮어쓰기 → 모델 실행(상수 덮어쓰기만 다른 같은 컴파일 결과 재사용) → **모델의 모든 지표**(카탈로그 `kpiSpecs`)를 계산해 저장. 시계열은 지표 계산에만 쓰고 버린다. 선택한 변수 하나는 **1일 간격 표본**을 모아 확률 구간 띠(P10~P90)를 그릴 수 있다(반복 1,000 × 400일 × 8바이트 ≈ 3 MB).

| 항목 | 값 |
|---|---|
| 반복 수 N | 기본 500, 최소 20(분포를 그리기엔 부족하다는 경고는 100 미만에서), 최대 5,000. 책: 50~100회가 분포를 채우는 최소, 최대 1,000회면 많은 경우 충분(A.3.2) |
| 시드 | 기본 1, 사용자가 지정. 프로젝트에 저장 |
| 비용 | 통합 모델 1회 약 4.5 ms(측정). N = 1,000 → 약 5초, N = 5,000 → 약 23초. Brooks는 약 0.5 ms |

### 4.2 Worker 실행 (E6, 새 메시지)

기존 Worker에 `montecarlo` 요청을 더한다(2차의 `reforecast` 요청과 같은 방식). 요청: 모델, 기준 파라미터(대상 시나리오의 유효 파라미터), 실행 설정, 분포 목록, N, 시드, 시계열을 모을 변수(선택). Worker는 `executeRun`처럼 **12 ms마다 이벤트 루프에 양보**하며 진행하고 취소 메시지를 확인한다.

| 메시지 | 내용 |
|---|---|
| `mcProgress` | 끝난 반복 수, 총 반복 수, 지금까지의 지표 배열(선택: 5% 또는 250 ms마다) — 화면이 진행 중에도 히스토그램을 갱신한다 |
| `mcDone` | 입력 표본 `[파라미터][반복]`, 지표 `[지표][반복]`(계산 불가는 NaN), 실패한 반복 목록과 이유, 시계열 띠 자료, 취소 여부와 끝난 반복 수. 버퍼는 전송(transfer)한다 |
| `error` | 요청 자체가 잘못됨(알 수 없는 모델, 분포 검증 실패) |

한 반복의 실패(`SimulationError`: NaN 등)는 그 반복만 제외하고 계속한다. 제외된 반복이 전체의 10%를 넘으면 "입력 분포가 모델이 허용하지 않는 조합을 만든다"고 경고하고 실패한 입력 요약(가장 흔한 파라미터 값 구간)을 보인다. 취소하면 끝난 반복의 결과를 유지하고 "N회 중 k회" 표시를 붙인다(SC-07 대안 흐름).

### 4.3 일괄 실행과의 관계

시나리오 일괄 실행(04번 문서)과 별개의 흐름이다. 둘이 같은 Worker를 쓰므로 한 번에 하나만 실행한다(일괄·재예측·조치 시험·Monte Carlo 상호 배제). 하나의 Worker로 순차 실행한다. 병렬 Worker는 반복이 독립이므로(3.1) 필요해지면 후속으로 붙인다.

## 5. 출력 분석 (RSK-03, RSK-04, RSK-07, RSK-08)

### 5.1 요약 통계 [표준 통계, 책 A.6]

지표마다: 개수, 평균, 표준편차, 최소, 최대, 백분위수 P10·P25·P50·P75·P80·P90·P95(선형 보간, 표본 `n`개 중 `(n−1)p + 1`번째), 완료하지 못한 반복의 비율(미완료는 지표 값이 없으므로 분포에서 빼고 **비율로 따로 보인다**. 완료일 분포가 "끝난 것만의 분포"임을 화면에 명시한다).

**평균의 신뢰구간**(책 A.6.1): `X̄ ± t(α/2, n−1) · s / √n`. 책은 n ≥ 30이면 정규(Z), 30 미만이면 t 분포를 쓰라고 한다. 구현은 t 분위수 함수 하나로 둘을 모두 처리한다(n이 크면 Z에 수렴). 시험은 책의 예제를 쓴다: n = 16, 평균 238, 표준편차 58.8 → 90% 구간 **212 ~ 264**(책 A.6.1.1).

**분위수의 신뢰구간** [표준 통계]: 정렬한 표본의 순위로 구한다. P80이 점 추정 하나로 보이지 않도록 "P80 = 305일 (95% 구간 298 ~ 313)"처럼 보인다.

### 5.2 분포 화면 (RSK-03)

| 요소 | 설명 |
|---|---|
| 히스토그램 | 구간 수는 Sturges `⌈log₂ n⌉ + 1`을 기본으로 하고 사용자가 바꾼다. 구간 경계는 보기 좋은 수로 맞춘다. 책 그림 A.20과 같은 구성 |
| 신뢰 수준 차트 | 누적분포. 세로 = "이 값 이하로 끝날 확률"(책의 confidence level, "신뢰 수준 = 주어진 값을 넘지 않을 확률"). 책 그림 A.21. P50·P80·P90 점선과 목표선을 겹친다 |
| 시계열 띠 | 선택한 변수(기본: 누적 공수)의 중앙값과 P10~P90 띠, 기준(결정적) 실행의 곡선 |
| 지표 선택 | 모델의 지표 전체(일정·비용·품질·위험 그룹)를 고른다 |

### 5.3 목표 달성 확률 (RSK-04)

목표 하나는 `지표 ≤ 값`(방향이 낮을수록 좋은 지표) 또는 `≥`이다. 확률 = 목표를 만족한 반복 수 / **N**(완료하지 못한 반복은 만족하지 못한 것으로 센다). 이항 비율의 **Wilson 구간**(95%)을 함께 보인다 [표준 통계]. 두 목표(예: 완료일 ≤ 계획 AND 총 공수 ≤ 예산)의 **동시 달성 확률**은 같은 반복의 쌍으로 센다.

기본 목표는 **채택 계획**이 있으면 그 계획 완료일과 BAC이다(05번 문서의 기준선). 목표를 입력하지 않으면 "80% 신뢰 수준 값(P80)", "필요한 여유(P80 − P50, 일·%)"를 보인다. 책(A.1): 비용은 비용 여유를 넉넉한 부분까지 잡고, 기대치는 점이 아니라 범위로 말하라.

### 5.4 시나리오 간 비교 확률 (RSK-07)

시나리오 둘 이상(최대 3개)을 **같은 표본**(같은 시드·같은 `r(i, p)`; 시나리오 간에 다른 파라미터는 그대로 덮어쓴 뒤 분포를 적용)으로 실행하면 **공통난수**(common random numbers)가 되어 차이의 분산이 줄고 쌍별 비교가 정당해진다 [표준 통계]. 결과: 각 시나리오의 분포를 한 차트에 겹치고 "A가 B보다 먼저 끝날 확률", 쌍별 차이(B − A)의 평균과 신뢰구간, "순위가 뒤바뀌는 반복의 비율"을 보인다. 책 2.8.2의 **정책 민감도**("가장 중요한 민감도는 정책 결론이 불확실성에도 유지되는가")에 대한 직접 답이다.

### 5.5 수렴 진단 (RSK-08)

"반복이 충분한가"를 눈으로 확인한다. 누적 평균과 P80을 반복 수에 따라 그리고(10%씩), 평균의 신뢰구간 반폭 `h = t·s/√n`을 보인다. 목표 반폭 `h*`를 입력하면 필요한 반복 수 `n ≥ (z·s/h*)²`(책 A.6.1의 표본 크기 관계)를 계산해 "현재 N이 부족합니다"를 알린다. N이 100 미만이면 분포가 거칠다는 경고를 항상 보인다.

## 6. 민감도 분석 (RSK-05)

책 2.8.2는 파라미터 변화에 대한 **수치·행동·정책** 민감도를 구분하고, 레버리지가 큰 파라미터를 찾으라고 한다. 두 가지를 제공한다.

### 6.1 한 번에 하나씩(OAT) 스윕과 토네이도

| 항목 | 설명 |
|---|---|
| 스윕 | 파라미터 하나를 범위의 `k`개 수준(기본 9, 3~21)으로 바꿔 지표 곡선을 그린다. 정수 파라미터는 정수 수준만 |
| 토네이도 | 선택한 파라미터 여러 개를 각각 낮은 값·높은 값으로 바꿔(나머지는 기준) 지표의 변화 폭을 막대로 그린다. 폭이 큰 순서로 정렬. 낮은/높은 값의 기본은 **분포의 P10/P90**(분포가 없으면 `±20%`로 허용 범위 안) |
| 의미 | 변화 폭이 작은 파라미터는 정밀한 추정이 필요 없다(책 2.8.2). 큰 파라미터는 레버리지 지점이거나 추정에 공을 들일 대상이다 |
| 비용 | 파라미터 수 × 2 + 1회 실행. 즉시 끝남 |

### 6.2 Monte Carlo 순위상관

Monte Carlo 결과에서 입력 표본과 출력의 **Spearman 순위상관**을 구해 같은 토네이도 형식으로 보인다 [표준 통계]. 파라미터가 동시에 흔들릴 때의 기여를 반영한다(OAT는 상호작용을 못 본다). 비선형이지만 단조인 관계에도 맞고 추가 실행이 필요 없다. 해석 문구: "상관은 인과나 크기가 아니다. 단조 관계의 강도다". 두 토네이도가 크게 다르면 상호작용이나 비단조 효과의 신호이므로 그렇게 안내한다.

### 6.3 실험 설계(RSK-06, 후속)

2^k 요인 설계(A.5)와 반응 표면(예: Brooks 법칙 모델의 투입 인원 × 진척 차이 임계값, 책 그림 A.23)은 3차 구현에서 제외한다. 일괄 실행(04번)이 이미 "입력 조합 목록을 순차 실행"을 하므로 요인 배치를 만들어 넣는 얇은 층으로 후속에 붙일 수 있다.

## 8. 프로젝트 파일

결과는 **저장하지 않는다**(입력과 시드로 항상 같은 결과가 나온다, NFR-05). 입력만 저장한다.

```jsonc
"risk": {                                    // 없으면 null
```

## 10. 시험 계획

| 대상 | 시험 |
|---|---|
| 분포 | `ppf(cdf(x)) = x`, 알려진 분위수(정규 0.975 → 1.96, 삼각·PERT의 닫힌 식과 평균 (a+4m+b)/6), **책의 표본**(정규 N(50,10²): r = 0.42 → 약 48, 0.86 → 약 61, 0.321 → 45.4), 절단 정규가 범위를 벗어나지 않음, 퇴화 분포 = 고정값, 정수 반올림, 검증 오류 |
| 표본 추출 | 같은 시드 = 같은 표본, N을 늘려도 앞부분 불변, 파라미터를 더하거나 빼도 나머지 불변, 서로 다른 시드의 독립성(상관 ≈ 0), 표본 평균·분산이 이론값에 수렴(허용 오차 안에서) |
| 통계 | 백분위수(손으로 계산한 작은 표본, 보간), 평균 신뢰구간 = **책의 예제 212~264**(평균 238·표준편차 58.8·n = 16·t = 1.75를 입력으로 넣는다. 참고: 책 표 A.4의 16개 값에서 직접 계산하면 평균 244.7·표준편차 46.6으로 본문 예제와 다르다. 본문 예제는 요약 통계로만 검증한다), 분위수 구간, Wilson 구간(경계 0과 1), 히스토그램 도수의 합 = 개수, Spearman(완전 단조 = ±1, 동순위), 수렴 곡선의 마지막 점 = 전체 통계 |
| Monte Carlo | 퇴화 분포만 있으면 결정적 실행과 **비트 동일**, **단조 모델에서 분위수 보존**(Brooks의 완료일은 공칭 생산성에 대해 단조 감소 → 완료일의 P80 = 생산성의 P20에서의 완료일, 큰 N에서 오차 한계 안), 취소·부분 결과, 일부 반복 실패 격리, 미완료 비율, 목표 확률 경계(목표 = 최소 → 0, 목표 = 최대 → 1), 동시 달성 ≤ 각 확률의 최소, 공통난수에서 같은 시나리오 두 개의 차이 = 0 |
| 민감도 | 선형에 가까운 단순 모델에서 토네이도 순서, 정수 수준, OAT와 Monte Carlo 순위의 일치(단조·독립 입력일 때), 영향 없는 파라미터의 폭 = 0 |
| 성능 | 통합 모델 N = 1,000이 Worker에서 20초 이내이고 진행 메시지가 UI를 막지 않는다(양보 시간 12 ms) |
| E2E(Electron) | 입력 선택 → 실행 → 진행·취소 → 분포·목표·민감도·수렴 확인 → 저장·열기 후 입력 복원과 같은 시드의 같은 결과 |
