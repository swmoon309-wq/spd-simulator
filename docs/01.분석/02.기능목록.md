# 기능 목록

소프트웨어 프로젝트 계획 수립 및 제어 시뮬레이터(Electron 로컬 앱)의 기능 목록.
시나리오는 [01.사용시나리오.md](01.사용시나리오.md)를 따른다. 근거 문서는 `docs/ref`(Madachy, *Software Process Dynamics*)이며 해당 장·절을 함께 적는다.

우선순위: **상** 필수 / **중** 권장 / **하** 선택

## 단계 정의

| 단계 | 목표 |
|---|---|
| MVP | 프로젝트 입력 → 시뮬레이션 → 결과 확인까지 한 흐름 완성 |
| 2차 | 정책 시나리오 비교, Earned Value 기반 통제 (구현 완료. SCN-07, COM-02, COM-05는 이후 구현, [구현 현황](../03.구현/09.구현현황.md)) |
| 3차 | 불확실성 분석, 모델 검증 (구현 완료. 위험 분석 RSK-01~05·07·08과 모델 검증 VAL-01~07. 위험 분석 결과 CSV 내보내기 포함. RSK-06만 제외, [구현 현황](../03.구현/09.구현현황.md)) |
| 4차 | 모델 편집, 보고서 (구현 완료. 보고서 RPT-01~08은 "종합" 보고서만 남기고, 모델 편집기 EDT-01~09와 COM-04는 M0~M5로 모두 구현, [구현 현황](../03.구현/09.구현현황.md)) |

## 1. MVP

### 3.1 민감도·위험 분석 (RSK)

근거: 2장 2.8.2~2.8.3, 부록 A. **분석 결과는 입력 분포와 보정되지 않은 모델의 가정에서 나온다**(설계 0장). 시나리오 간 상대 비교(RSK-07)를 먼저 권한다.

| ID | 기능 | 설명 | 시나리오 | 우선순위 |
|---|---|---|---|---|
| RSK-01 | 파라미터 분포 지정 | 균등·삼각·PERT·절단 정규 4종(역변환, 책 A.3.1). 파라미터 허용 범위 안, 정수는 반올림, 독립 추출. 기본 설정 기준 분포 템플릿 제안 | SC-07 | 상 |
| RSK-02 | Monte Carlo 실행 | N회(기본 500, 최대 5,000), 시드 지정, 반복·파라미터별 독립 난수(시드 재현, 반복 수를 늘려도 앞부분 불변), 진행률, 취소(그때까지 결과 유지), 반복 실패 격리 | SC-07 | 상 |
| RSK-03 | 결과 분포 | 히스토그램, 누적분포(신뢰 수준 차트), 요약 통계, 평균의 신뢰구간과 분위수의 신뢰구간, 시계열 확률 띠 | SC-07 | 상 |
| RSK-04 | 목표 달성 확률 | 일정·비용·품질 목표 대비 확률(Wilson 구간), 두 목표의 동시 달성 확률, 채택 계획의 완료일·BAC를 기본 목표로 | SC-07 | 상 |
| RSK-05 | 민감도 스윕 | 단일 파라미터 스윕, 토네이도 두 가지(한 번에 하나씩 / Monte Carlo 순위상관) | SC-07 | 중 |
| RSK-07 | 시나리오 간 비교 확률 | 같은 난수로 시나리오 최대 3개를 실행해 "A가 B보다 빠를 확률"과 쌍별 차이(정책 민감도, 책 2.8.2) | SC-07 | 상 |
| RSK-08 | 수렴 진단 | 반복 수가 충분한지: 누적 평균·분위수 곡선, 신뢰구간 반폭, 필요한 반복 수 | SC-07 | 중 |

## 8. 제약과 미결 사항

1. 책의 `.itm` 모델 파일은 `docs/ref`에 없다. 모델과 파라미터는 책의 서술과 그림을 근거로 새로 구현·보정해야 한다. 원본 수치와의 완전 일치는 보장하지 않는다.
2. 기술 스택(UI 프레임워크, 차트 라이브러리)은 설계 단계에서 결정한다.
3. MDL-02 4섹터 단순판의 변수 목록과 수식은 책 6.3을 근거로 설계 단계에서 확정한다. 그림에만 있는 파라미터는 보정이 필요하다.
