## 1. 분포 (`distributions.ts`)

모든 분포는 **균등난수 하나**를 받아 **역변환**(책 A.3.1)으로 값을 만든다. 난수열이 가변인 방법을 쓰지 않으므로 분포를 바꿔도 같은 `u`로 비교할 수 있다.

| 요소 | 구현 |
|---|---|
| `DistSpec` | `uniform {min,max}`, `triangular {min,mode,max}`, `pert {min,mode,max}`, `normal {mean,sd,lo?,hi?}`(절단 범위는 선택) |
| `validateDist(d, bounds?)` | 값의 유한성, 순서(최소 ≤ 최빈 ≤ 최대, 정규의 sd > 0과 절단 범위 `lo < hi`), 절단 범위에 확률이 거의 없는 경우(< 1e-9), **지지구간이 파라미터 허용 범위 안**인지를 한국어 메시지로 검사. 최소 = 최대(퇴화)는 허용 |
| `resolveDist` | 정규의 절단 범위를 파라미터 허용 범위로 채운다(설계 2.3). 다른 분포는 그대로 |
| `cdf`, `ppf`, `support`, `distMean` | 누적·역누적·지지구간·평균. `ppf`는 `u`를 [0, 1]로 제한하고 결과는 항상 지지구간 안(절단 정규의 끝점은 정확히 `lo`·`hi`). 삼각은 닫힌 식이고 엔진의 `RANDOM_TRIANGULAR`와 같은 식이다. PERT는 베타(α = 1 + 4(m−a)/(b−a), β = 1 + 4(b−m)/(b−a))의 역누적을 `[a, b]`에 사상. 절단 정규는 `u`를 `[F(lo), F(hi)]`로 사상한 뒤 역변환 |

수치 함수를 직접 구현했다(라이브러리 없이).

| 함수 | 방법 | 정확도 |
|---|---|---|
| `normalCdf` | `erfc`: 작은 인자는 급수, 큰 인자는 연분수 | 배정밀도에 가깝다 |
| `normalPpf` | Acklam의 유리 근사 + Halley 보정 1회 | `ppf(cdf(x)) = x`가 \|x\| ≤ 6에서 1e-7 안, 알려진 값은 1e-12 안 |
| `betaCdf`(정규화 불완전 베타), `betaPpf` | Lentz 연분수, 이분법 80회 | 역관계 1e-10 |
| `tCdf`, `tPpf` | 불완전 베타로 t 누적, 이분법으로 분위수. 중앙값은 정확히 0, df > 1e6은 정규 | 표의 값(0.95·df 15 = 1.7531 등) 4자리 일치 |

**책의 예제로 검증**: N(50, 10²)에서 r = 0.42 → 47.98(책 48), r = 0.86 → 60.8(책 61), r = 0.321 → 45.4, r = 0.55 → 51.3, r = 0.954 → 66.8(책 표 A.3).

## 2. 표본 추출 (`sampling.ts`)

- **반복·이름마다 독립인 난수**: `uniformFor(시드, 반복 i, 입력 이름)` = `Rng(mixSeed(시드, i, 이름)).next()`를 (1e-12, 1 − 1e-12)로 제한한 값. `mixSeed`는 이름의 FNV-1a 해시에 시드와 `i + 1`을 정수 곱셈으로 섞고 murmur3의 `fmix32`를 두 번 거친다. 모델이 난수 함수를 쓰면 모델 시드도 `modelSeedFor(시드, i)`(이름 `@model`)로 반복마다 유도한다.
- 얻는 성질(모두 시험으로 확인): 같은 (시드, 입력)은 같은 표본, **반복 수를 늘려도 앞부분이 같다**, **입력을 더하거나 빼도 다른 입력의 표본이 같다**, 취소해도 끝난 반복이 완전한 결과, 반복을 어떤 순서·병렬로 돌려도 같다(반복이 서로 의존하지 않음).
- `InputSpec {name, dist, min, max, integer?}`: 입력 하나(파라미터, 분포, 폼의 허용 범위, 정수 여부). `validateInput`/`validateInputs`는 분포가 허용 범위 안인지, 정수 범위가 비지 않았는지, 이름이 겹치지 않는지를 검사한다.
- `sampleInput`: 역변환 → 허용 범위로 제한 → 정수면 반올림하고 정수 범위로 제한. `sampleRow`는 입력 목록의 한 반복 표본.
- `defaultRange`: 분포의 P10·P90(정수는 반올림) — 토네이도의 기본 낮은/높은 값.
- `templateDist(v, 범위)`: 삼각(0.8v, v, 1.3v)을 허용 범위로 자르고 최소 ≤ 최빈 ≤ 최대가 되게 정렬한다(음수 값에서도).

## 3. 통계 (`stats.ts`)

| 함수 | 내용 |
|---|---|
| `percentileSorted` | 선형 보간(R·numpy의 type 7과 같음), `summarize`(n, 평균, 표본 표준편차 n−1, 최소, 최대, P10·P25·P50·P75·P80·P90·P95) — 유한하지 않은 값은 제외 |
| `meanCI(평균, sd, n, 수준)` | 책 A.6.1의 `평균 ± t(α/2, n−1)·s/√n`. 책은 n ≥ 30이면 정규, 미만이면 t를 쓰라고 하는데 t 분위수는 n이 크면 정규에 수렴하므로 **하나의 식**으로 처리한다. **책 예제 재현**: n = 16, 평균 238, 표준편차 58.8, 90% → 212.2 ~ 263.8(책 212 ~ 264) |
| `quantileCI` | 정렬한 표본의 순위(정규 근사 `np ± z√(np(1−p))`)로 분위수의 구간. 균등 표본 400회 시험에서 95% 구간의 포함률이 90~99% |
| `wilson(k, n)` | 이항 비율의 Wilson 구간. **경계에서 한쪽 끝이 정확히 0·1**(처음 구현은 부동소수 오차로 2.8e-17이 나와 고쳤다). 알려진 값 5/10 → 0.2366 ~ 0.7634 |
| `requiredSamples` | 책의 표본 크기 관계 `n ≥ (z·s/h)²` |
| `histogram` | 구간 수 기본 Sturges `⌈log₂ n⌉ + 1`(n = 100 → 8), 경계는 1·2·2.5·5×10^k 중 보기 좋은 폭(`niceStep`), 마지막 구간은 오른쪽 끝 포함(도수의 합 = 값의 개수), 값이 모두 같으면 구간 하나 |
| `ecdf`, `cdfAtSorted` | 경험적 누적분포, `x` 이하의 비율(이분 탐색) |
| `pearson`, `ranks`, `spearman` | 유한한 쌍만, 동순위는 평균 순위, 분산 0이면 NaN |
| `convergence` | 표본을 앞에서부터 `steps`등분해 누적 평균·분위수·평균 신뢰구간 반폭. 마지막 점 = 전체 통계(시험) |

## 4. Monte Carlo (`montecarlo.ts`)

### 4.1 실행기

`McInput {model, baseParams, options{end,dt}, inputs, n, seed, kpis, band?}`. `validateMc`: 반복 1~5,000의 정수, 입력 ≥ 1, 입력은 모델의 **상수**(Level 이름 등은 거부), 분포·허용 범위·이름 중복, 지표 ≥ 1. 문제가 있으면 `McError`.

`McRunner`는 반복을 `step(k)`로 조금씩 진행한다(Worker가 사이사이 취소·양보를 처리하기 위한 형태). 반복 `i`: `sampleRow` → `baseParams` 위에 덮어써 모델 실행(상수 덮어쓰기만 다른 같은 컴파일 결과 재사용, 모델 시드는 유도) → 모든 지표 계산 → 선택한 변수가 있으면 **1일 간격** 값을 행렬에 기록(점 수 = ⌊종료 − 시작⌋ + 1). `SimulationError`(NaN 등)만 실패로 격리해 `failures`(반복 번호, 메시지, 입력 표본)에 기록하고 계속한다. **다른 오류는 그대로 던진다**(요청 자체의 오류를 숨기지 않기 위해). `result()`는 끝난 반복만 담은 복사본이라 **취소한 뒤에도 완전한 결과**다. `runMonteCarlo`는 동기 실행(진행 콜백, `shouldStop`).

`McResult`: 입력별 표본(`Float64Array`), 지표별 값(**계산할 수 없는 값과 실패한 반복은 NaN**), 반복별 상태(0 성공, 1 실패), 실패 목록, 시계열 띠 행렬.

### 4.2 집계

| 함수 | 정의 |
|---|---|
| `kpiDistribution` | 성공 수 `nOk`, 실패 수 `nFailed`, **지표를 계산할 수 없는 성공 반복 수 `nUndefined`와 비율**(예: 종료 안에 끝나지 않음), 지표가 있는 값의 요약·정렬값·평균의 신뢰구간. 분포는 "끝난 반복만의 분포"이며 미완료는 비율로 따로 보인다 |
| `kpiHistogram` | 위 분포의 히스토그램(도수의 합 = 지표가 있는 성공 반복 수) |
| `targetProbability` | 목표(들)를 **모두** 만족한 반복의 비율 = 동시 달성 확률. 분모는 **성공한 반복 수**(실패 제외), 지표를 계산할 수 없는 반복은 **만족하지 못한 것**으로 센다. Wilson 구간. `<=`·`>=`. 목표가 없으면 1 |
| `compareResults(a, b, 지표)` | **공통난수** 쌍별 비교: 시드·반복 수·입력 이름이 같고 **입력 표본이 비트 단위로 같아야** 한다(아니면 `McError`). 둘 다 성공하고 지표가 있는 반복의 수, 한쪽만 있는 수, P(A < B), 동률, 차이(B − A)의 평균과 신뢰구간, 중앙값 기준 우열과 반대인 반복의 비율(뒤바뀜) |
| `bandSummary` | 1일마다 성공한 반복의 P10·P50·P90 |

## 7. 설계와 달라진 점

- 분포 평균 함수를 `distMean`으로 이름 지었다(`mean`은 너무 일반적).
- 반복 수의 하한은 분석 계층에서 1이다(설계의 "최소 20"은 화면의 입력 검사에서 건다).
- `McRunner`가 `Simulation`을 직접 쓰므로 `analysis`가 엔진을 런타임에 사용한다(이전에는 타입만 썼다). 2차의 재예측(`reforecast`)이 이미 그렇게 쓰고 있다.
- 이 시험에서 쓰는 Brooks 지표(`completionDay`, `totalEffort`)는 시험 파일 안에 정의했다. 화면에서는 카탈로그의 `kpiSpecs`를 쓴다.
