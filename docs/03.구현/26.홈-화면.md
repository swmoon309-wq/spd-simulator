## 1. 한 일

앱의 **첫 화면을 "홈" 탭**으로 만들었다(탭 순서: 홈·실험·시나리오·통제·위험 분석·검증). 홈은 두 열이다.

| 영역 | 기능 | 내용 |
|---|---|---|
| 왼쪽: **현재 프로젝트** | PRJ-04, PRJ-01 | 이름·저장 상태·모델, **설명 편집**, 마지막 실행 요약(일정·공수·결함·인력), 구성(시나리오 수·채택 계획·실적 수), 실험·시나리오·통제로 가는 버튼 |
| 오른쪽: **새 프로젝트** | PRJ-01 | 이름·모델·설명으로 시작 |
| 오른쪽: **열기** | PRJ-02 | 파일에서 열기와 **최근 프로젝트** 목록 |
| 오른쪽: **예제** | PRJ-03, NFR-07 | 내장 예제를 **복사본으로** 열기 |

## 2. PRJ-01 이름·설명

- **설명**은 프로젝트 파일의 `meta.description`(선택, 최대 1,000자)에 저장한다. 없어도 되고, **파일 버전은 올리지 않았다**(설명이 없는 옛 파일이 그대로 열린다). 설명을 고치면 "수정됨"이 되고 실행 취소 기록에도 들어간다("프로젝트 설명 변경", 글자를 치는 중에는 한 단계로 합쳐진다).
- **이름**은 지금까지처럼 파일 이름이 정한다(저장·열기 때 파일 이름을 따른다). 새 프로젝트를 만들 때 적은 이름은 **처음 저장할 때 파일 이름의 기본값**이 된다(화면에 그렇게 적었다). 비우면 "이름 없는 프로젝트".
- 새 프로젝트를 이름·설명으로 시작하면 수정되지 않은 상태다. 저장하지 않은 변경이 있으면 먼저 묻는다(`startProject`).
- 코드: `ProjectSlice.projectDescription`·`setProjectDescription`·`newProject(modelId, { name, description })`, `shared/projectFile.ts`, `lib/projectApply.ts`, `lib/params.ts`의 `snapshotOf`(맨 뒤 인자로 설명을 더했다).

## 3. PRJ-02 최근 목록

- main이 앱 데이터 폴더의 `recent.json`에 **최대 10개**(가장 최근이 맨 앞)를 둔다(`main/recentService.ts`). 열거나 저장하면 앞으로 올라온다. 읽거나 쓰지 못해도 오류로 알리지 않는다(편의 기능이다).
- **renderer에는 경로를 주지 않는다**(기존 규칙). 파일 이름·폴더 이름·시각·`missing`과 경로에서 만든 짧은 식별자만 알리고, 열 때는 식별자를 main이 경로로 되돌린다. 모르는 식별자는 거절한다.
- 파일이 없어진 항목은 흐리게 보이고 열 수 없다. 그래도 열려고 하면(오래 열어 둔 화면 등) "파일을 찾을 수 없습니다. … 목록에서 뺐습니다."라고 알리고 목록에서 뺀다. 항목마다 **빼기**, 전체 **목록 지우기**(파일은 지워지지 않는다)가 있다.
- 열기 전에 저장하지 않은 변경이 있으면 묻는다(`openRecent`). 대화상자 없이 열도록 `ProjectService.openPath`를 분리했다(`open`은 대화상자 뒤에 같은 함수를 쓴다).
- 브라우저(개발용)에서는 "데스크톱 앱에서만 사용할 수 있습니다".

## 4. PRJ-03 예제 열기와 NFR-07

- 예제는 **파일이 아니라 코드**(`lib/examples.ts`)에서 만든다. 카탈로그의 모델마다 하나: 기본 설정으로 시작하고, 모델의 프리셋을 시나리오로 가진다(기본값과 같은 "추가 없음"·"현재 설정"은 기준과 같아 뺀다). 이름은 "<모델> 예제", 설명은 모델 설명.
  - Brooks 법칙 예제: 시나리오 `5명 추가`, `10명 추가`.
  - 통합 프로젝트 예제: `과소추정 없음`, `일정 촉박(120일)`, `빠른 채용·동화`.
- **복사본으로 연다**(`openExample`): 어떤 파일에도 연결되지 않고(저장하면 이름을 묻는 새 파일), 열었을 때는 수정되지 않은 상태이며, 안내가 뜬다. 고쳐도 원본은 바뀌지 않는다(열 때마다 새로 만든다). 이것이 NFR-07(예제 보호)이다.
- 프리셋이 둘 이상인 예제는 열고 나서 **기준 실행이 끝나면 프리셋을 모두 실행**해 실험 탭에서 결과가 겹쳐 보인다(SC-02의 "인력 추가 없는 경우와 추가한 경우가 같은 그래프에 겹쳐").
- 열면 실험 탭으로 이동한다.

## 5. PRJ-04 요약 카드

`lib/homeSummary.ts`(`summarizeLastRun`): 마지막 **실행 기록**을 모델의 지표 정의(`kpiSpecs`)로 계산해, 그룹마다 첫 지표를 보인다: **일정**(완료일), **공수**(총 투입 공수), **결함**(잔존 결함 추정)과 **인력**(최대 인원). 모델에 없는 그룹은 건너뛴다(Brooks 모델은 결함 지표가 없어 세 칸). 종료 시각 안에 끝나지 않은 완료일은 "미완료", 계산할 수 없는 값은 "–". 실행 기록이 없으면 안내 문구.
기능 목록의 "마지막 실행 결과"를 **실행 기록의 마지막**으로 해석했다(시나리오 일괄 실행 결과가 아니다). 일괄 실행 요약은 시나리오 탭의 비교 화면이 맡는다.

## 7. 알아둘 것

- 시작 화면이 실험 탭에서 홈으로 바뀌었다. 저장소 밖의 Electron E2E 스크립트가 첫 화면을 실험 탭으로 가정하고 있다면 탭을 먼저 눌러야 한다.
- 홈의 "새 프로젝트"와 상단의 "새 프로젝트" 버튼은 다르다: 상단 버튼은 지금 모델로 이름·설명 없이 바로 새로 시작하고, 홈은 이름·모델·설명을 받는다.
