# 모델 검증: 오차 지표와 정렬 (설계 07의 순서 1)

설계: [07.모델검증설계.md](../02.설계/07.모델검증설계.md) 2~3장(VAL-01·02의 계산 부분), 10장 시험 계획의 지표·정렬. 화면·데이터셋·파일 저장은 순서 2.

## 1. 구현한 것

`packages/analysis/src/validation/`에 순수 계산 두 모듈을 만들고 `@spd/analysis`에서 내보냈다. 화면과 스토어는 아직 건드리지 않았다.

| 모듈 | 내용 |
|---|---|
| `align.ts` | `toSimTime`(`t_sim = t_data × 단위 + 이동`, 단위는 일·주·월=30.4375일), `alignColumn`(관측 열을 시뮬레이션 결과와 짝지음: 시각 변환 → 범위 밖·유한하지 않은 점 제외 → 시간순 정렬(같은 시각은 입력 순서) → 값 배율(관측에만) → 시뮬레이션 값은 `valueAt` 선형 보간). 제외한 점은 `outOfRange`·`invalid` 개수로 알린다. 모델에 없는 변수·유한하지 않은 배율·이동은 `AlignError` |
| `metrics.ts` | `computeMetrics`: n, ME, MAE, RMSE, 정규화 RMSE, MRE, MAPE(O = 0인 점은 두 지표에서만 빼고 `zeroObserved`로 알림), NSE, 상관 r·R², Theil U, **Theil 분해(편향·변동 크기·비체계 몫)**, 추세 일치율. 유한하지 않은 짝은 뺀다. `checkTolerances`(허용 기준 안/밖/알 수 없음), `completionError`(시뮬레이션 − 실제 완료일, 일과 %), `weightedNrmse`(보정 목적함수 `J = Σ w·NRMSE²`와 같은 정의, 기본 가중치 1/열 수) |

## 2. 정한 것(설계에서 구체화)

- **Theil 분해는 모집단 표준편차(n으로 나눔)를 쓴다.** 그래야 `MSE = (S̄−Ō)² + (sS−sO)² + 2(1−r)·sS·sO`가 정확히 성립해 세 몫의 합이 1이다. 한쪽이 상수면 상관이 정의되지 않지만 교차항은 0이므로 합 1이 유지된다. 오차가 0이면 분해는 정의되지 않아 NaN이다.
- **NSE**: 관측이 상수이면 NaN, 상수이고 완전 일치면 1.
- **추세 일치율**: 인접 구간의 변화 방향(증가·감소·같음)이 같으면 일치로 센다. 같음끼리도 일치이다. 짝이 2개 미만이면 NaN.
- **허용 기준은 기본값이 없다**(설계 12장 결정: 도구가 기준을 정하면 거짓 확신을 준다). `nrmse`·`mape`는 이하, `mre`는 절댓값 이하, `nse`·`trend`는 이상이면 "안"이고, 기준을 정하지 않은 지표는 판정하지 않는다. "합격·불합격"이라는 값은 없다.
- 12장의 나머지 결정(데이터 저장 상한 합계 5만 점·5개·20열, 보정은 Nelder–Mead 최대 5개, 교란은 상수에만)은 제안대로 확정했고 해당 순서(2, 4, 6)에서 반영한다.
- 열 이름 자동 추천(`matchVariable`)은 카탈로그를 쓰는 화면 쪽 코드라 순서 2에서 다룬다(설계 10장의 "열 매핑 자동 추천" 시험도 그때).

## 3. 시험

`packages/analysis/test/validation.test.ts` 39개(analysis 392 → 431).

- **손계산**: O = [1, 2, 3, 4], S = [1.5, 2, 2.5, 5]에서 ME 0.25, MAE 0.5, RMSE √0.375, 정규화 RMSE, MRE, MAPE, NSE 0.7, 상관, U, Theil 편향 몫 1/6 등을 식으로 확인.
- **성질**: 완전 일치(오차 0, NSE 1, U 0, 상관 1), **Theil 분해의 합 = 1**(50개 임의 표본), 상수 시뮬레이션, 편향만 있는 경우(편향 몫 1, 상관은 1이지만 NSE는 음수 — 상관만으로 편향을 놓친다는 책의 경고를 재현), 같은 배율을 양쪽에 곱해도 정규화 지표·NSE·상관·U·몫·추세 불변, O = 0 제외, 관측 상수, 유한하지 않은 짝, 빈 입력·짝 하나, 길이 불일치, 추세 경계.
- **허용 기준·완료 시점 오차·종합 J**: 방향, 기준 없음, 알 수 없는 값, 시뮬레이션이 끝나지 않은 경우, 가중치, 열 제외.
- **정렬**: 시간 단위·이동 변환, 보간, 주 단위+이동, 값 배율, 범위 밖(양 끝 포함)과 유한하지 않은 점의 제외·개수, 순서 뒤섞인 입력, 빈 입력, 오류 3종.
- **실제 모델(Brooks)**: 같은 실행에서 뽑은 주 단위 "관측"은 오차 0·NSE 1, 인력 10명을 더 투입한 실행을 "실제"로 보면 시뮬레이션이 인원을 적게 보아 ME < 0·NSE < 1이고 분해 합이 1, 완료 시점 오차는 음수(Brooks 법칙: 인력을 더 넣으면 실제가 더 늦다).
