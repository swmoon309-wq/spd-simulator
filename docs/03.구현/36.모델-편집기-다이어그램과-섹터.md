**접근성(설계 9장)**: 캔버스에서만 할 수 있는 편집은 없다. 위치(자동 배치 외에는 효과 없음)를 뺀 모든 편집을 표·목록·속성으로도 할 수 있다 — 연결은 수식 편집과 Level의 유입·유출 체크박스, 섹터는 섹터 패널과 속성의 "섹터" 선택, 선 지우기는 수식 편집·체크 해제. 노드는 키보드로 초점을 옮겨 고르고(`nodesFocusable`) 노드·선에 읽을 이름("`A → B (정보)`")이 있다.

## 2. 설계와 달라진 것·알게 된 것

- **번들 크기**: 설계는 약 150 KB로 봤으나 메인 번들(JS)이 **3,343 → 3,934 kB(약 +590 kB)** 늘었다(미압축). 오프라인 앱이라 실행에는 영향이 작지만 기록해 둔다.
- **연결을 그릴 때의 수식 보조**: 설계는 "수식에 변수 이름을 넣어 준다"만 정했다. 구현은 수식이 `0`이거나 비었으면 이름으로 바꾸고, 아니면 끝에 ` * 이름`을 붙이고 "연산이 맞는지 확인하세요"를 알린다(곱이 SD에서 가장 흔한 영향 관계라서). Rate → Level은 **유입**에 더하고 유출은 속성이나 선을 골라 "유출로 바꾸기"로 한다(Level → Rate의 선은 정보 참조와 같은 방향이라 흐름으로 쓰지 않았다).
- **선 지우기**는 정보선이면 수식의 참조를 **0으로 바꾸고**(수식이 계속 컴파일된다) 흐름선이면 유입·유출에서 뺀다.
- 위치는 끌어 놓은 노드만 저장하고 나머지는 자동 배치를 따른다. 그래서 변수를 더하거나 지우면 저장되지 않은 노드는 다시 배치될 수 있다("자동 배치"로 전체를 다시 정한다).

전체: analysis 566, models 239, engine 269, **desktop 1,397**(+46) 통과. 타입 검사·`npm run build` 통과.

- `lib/modelEdit/diagram.test.ts` 46: **연결선 파생**(정보·지연·초기값·흐름, 수식을 바꾸면 선도 바뀜, 일반+지연 중복, 자기 참조·정의되지 않은 변수·테이블, 미완성 수식, 결정성). **자동 배치**: 내장 7개 모델 각각에서 모든 변수가 그려지고 **노드가 겹치지 않고 선의 끝이 모두 있음**, 같은 입력은 같은 배치(JSON 왕복 뒤에도), 흐름 방향(유입 Rate는 Level 왼쪽·상수는 그 앞), 구름이 붙는 곳, 저장된 위치 우선·자동 배치 되돌림, 큰 모델(100여 개)도 칸 하나에 노드 하나. **위치·섹터는 결과에 영향이 없음**(Brooks의 모든 변수 시계열 비트 동일), 이름 바꾸기·삭제가 위치·섹터를 따라감. **섹터**: 만들기·이름·색·지우기, 이름 규칙·최대 20개, 변수는 섹터 하나에만, 배경 상자가 멤버를 감쌈, **접으면 요약 노드·밖과의 선만·합친 선 개수·구름 숨김, 내장 7개 모두 섹터를 접어도 그림이 깨지지 않음**, 섹터 사이 연결 요약. **연결 편집**: 수식 보조(0이면 이름, 아니면 곱 + 확인 안내), 유입 연결, 거절 사유 7가지, 선 지우기(정보·지연·초기값·흐름), 흐름 방향 바꾸기.
- **실제 브라우저**: 모델 탭의 다이어그램에서 Brooks 사본을 열어 **28개 노드(상수·Level·Rate·Auxiliary·구름)와 34개 선(정보 22·초기값 3·흐름 9)**이 그려지고, 섹터 패널에서 "인력" 섹터를 만들어 변수 4개를 넣으면 **배경 상자**가 생기고, 접으면 **요약 노드 "인력 — 변수 4개(접힘)"**가 되어 노드가 24개로 줄며, 펼치면 돌아오는 것, **노드를 마우스 이벤트로 끌면 위치가 저장되고 이력에 "위치 이동"이 기록되는 것**, **핸들을 끌어 다른 노드에 놓으면 그 수식 끝에 `* hire_day`가 붙고 안내가 나오는 것**을 확인했다. 콘솔 오류 없음.

## 4. 확인하지 못한 것·남긴 것

- **Electron 앱에서 다이어그램을 직접 확인하지 못했다**(브라우저에서만). React Flow는 순수 DOM·SVG라 같게 동작할 것으로 보지만 Electron의 Chromium에서 보지는 않았다.
- **선 위에서의 선택·지우기, 선 모양(곡선 경로의 겹침)**은 사람이 보며 다듬을 여지가 있다. 선이 노드 뒤를 지나거나 서로 겹치는 것은 막지 않는다(노드 겹침만 보장한다).
- 합쳐진 선은 지울 수 없고(펼친 뒤 지운다), 접힌 섹터의 요약 노드는 끌어서 옮길 수 없다(위치를 저장하지 않는다).
- **초안 자동 저장·복구**는 여전히 없다.
- 키보드만으로 선(연결)을 새로 만드는 방법은 캔버스에 없다(수식·흐름 체크박스로 같은 편집을 한다). 캔버스 노드의 키보드 이동·연결을 더 지원하는 것은 후속이다.
