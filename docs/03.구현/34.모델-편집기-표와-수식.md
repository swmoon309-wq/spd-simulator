## 2. 설계와 달라진 것

- **탭 위치**: 설계는 검증 오른쪽이지만 **맨 끝(보고서 다음, Cmd/Ctrl+8)**에 두었다. 앞 탭의 단축키(보고서 Cmd/Ctrl+7)를 바꾸지 않으려는 것이다.
- **단위 검사(④)는 게이트에서 "건너뜀"**으로 보인다(M2).
- **이름 바꾸기 미리보기**: 바꾸기 전에 참조 목록을 보이는 대신, 속성 칸에 "이 변수를 쓰는 곳" 목록을 항상 보이고 바꾼 뒤 알림에 바꾼 수식 수를 적는다. 충돌하면 거절한다.
- **삭제 확인**: 참조 목록과 함께 거절한 뒤 "참조를 0으로 바꾸고 지우기" 버튼으로 진행한다(별도 대화상자 없음).
- 그래프 함수 표(테이블)는 편집하지 않고 보존만 한다(M4). 섹터·위치(view)도 보존만 한다(M3).

## 4. 확인하지 못한 것·남긴 것

- **Electron 앱에서 모델 탭을 직접 클릭해 보지 못했다**(브라우저에서만). 내 모델 저장·불러오기 IPC는 M0에서 Electron으로 확인했고 이 단계는 같은 경로를 쓴다.
- **초안 자동 저장·복구**(설계 9장 "저장")는 아직 없다. 편집 중인 초안은 앱을 닫으면 사라진다(적용한 모델은 내 모델 목록에 남는다). 다음 단계 전에 정할 일이다.
- 값 대입 시험(미리보기에서 일부 변수 값을 바꿔 보는 분석 보조)은 만들지 않았다. 시각 0의 값 미리보기만 있다.
- 큰 모델(변수 200개)에서 입력마다 lint·시각 0 계산을 동기로 돌린다. 내장 통합 모델(약 100개)에서 체감 지연은 없었지만 한도 크기에서는 측정하지 않았다.
- 화면 컴포넌트 자체의 자동 시험은 없다(브라우저 확인과 스토어·순수 함수 시험으로 대신했다).
