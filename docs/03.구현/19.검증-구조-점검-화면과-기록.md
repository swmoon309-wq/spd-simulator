## 2. 정한 것

- **오래된 결과는 기록에 넣지 않는다.** 입력이 바뀐 뒤의 구조 점검·극단 조건·데이터 비교는 "이 모델·이 입력"의 요약이 아니므로 제외하고, 미리보기에 "결과가 오래되어 넣지 않습니다(다시 실행하세요)"로 알린다. 데이터 비교는 대상 시뮬레이션이 최신(`done`)일 때만 넣는다.
- **기록은 하나**다(마지막으로 만든 것). 설계 8장의 `report` 필드가 하나이기 때문이다. 이력은 만들지 않는다.
- **기록에 합격·불합격이 없다.** 지표, 사용자가 정한 기준의 안/밖, 점검 결과(통과·주의·실패·정보), 사람이 적은 체크리스트만 담는다. 마크다운 맨 위에 "검증은 증명이 아니며 합격·불합격을 판정하지 않는다"고 적는다.
- **모델 버전이 다른 기록**은 열 때 경고하지 않고 화면과 내보낸 마크다운에 "다른 모델 버전(기록 v7, 현재 v1)"으로 표시한다(설계 6장).
- 체크리스트 항목은 책의 시험 이름을 따르되 기준 문구는 **제 문장으로 풀어 썼다**(원문을 옮기지 않음). 항목 id는 파일에 저장하는 안정적인 식별자이다. 열 때 모르는 id는 버리고 경고한다(앞으로 항목이 바뀌어도 이전 파일을 안전하게 연다).
- S5(쓰이지 않는 변수)에는 화면이 읽는 변수(`entry.variables`, Earned Value 어댑터의 단계 변수·공수 변수)를 `usedExternally`로 넘긴다. 지표 계산 함수가 읽는 변수는 알 수 없으므로 모델의 `outputs`로 선언해야 한다(함수 주석에 적음).

## 3. 점검에서 확인한 것

- **통합 모델의 S4가 "주의"로 나온다**(실제 발견). 완료일만 보면 dt 0.25와 0.125의 차이가 0.04%인데, 카탈로그의 **모든 지표**를 보면 "잔존 결함 추정·밀도"가 1.29% 변한다(1% 초과). 구조 점검은 이를 정직하게 보이고, 나머지(S1·S2·S3·S5·S6)는 통과한다. Brooks는 여섯 점검이 모두 통과한다. dt를 줄이면 개선되므로 결함이 아니라 "이 지표는 dt에 민감하다"는 정보이다.
- 처음에는 통과한 점검 카드를 접어 두었는데 E2E가 **"확인하지 못한 것"이 기본으로 보이지 않는다**는 것을 잡아내 모두 펼치도록 바꿨다.
