# 구현 현황 (MVP·2차 기능 목록 대비)

기준일 2026-10-22. `docs/01.분석/02.기능목록.md`의 ID별로 구현 여부를 코드와 구현 문서로 확인한 표이다. **완료** = 수용 기준까지 구현·시험, **부분** = 일부만, **미구현** = 아직 없음.

## 1. 요약

| 구분 | 항목 수 | 완료 | 부분 | 미구현 |
|---|---|---|---|---|
| MVP 기능(PRJ·CFG·SIM·MDL·RUN·RES) | 27 | 27 | 0 | 0 |
| 2차 기능(SCN·CTL·ENG·MDL-04·COM-02·COM-05) | 21 | 21 | 0 | 0 |
| MVP 단계 공통(COM-01·03·06) | 3 | 2 | 1 | 0 |
| 합계 | 51 | 50 | 1 | 0 |

3차(위험 분석·모델 검증)는 아래 6장에 따로 정리했다. 위 합계에는 넣지 않았다.

비기능 요구(NFR)는 4장에 따로 적었다.

핵심 시나리오 **SC-01~06은 모두 동작한다.** MVP·2차 기능은 설정의 언어·단위(COM-03의 일부)만 빼고 모두 구현했다. SLOC 환산 보조 입력(CFG-01)과 기본 구조 라이브러리(MDL-03)는 [28](28.SLOC-환산과-기본-구조-라이브러리.md)에서 구현했다. 메뉴·설정(테마)·도움말은 [27](27.메뉴-설정-도움말.md)에서 구현했다. 홈 화면(PRJ-01~04)은 [26](26.홈-화면.md)에서 구현했다. SCN-07·RES-02·SIM-05·RUN-01은 [24](24.사용-흐름-보강.md)에서 구현했다.

기준일 2026-10-22. **보고서는 R0~R4를 구현했다**([29](29.보고서-기반과-계획서-시나리오-비교.md)~[32](32.보고서-검증-절과-설정-저장.md)). 모델 편집기는 **M0(기반)~M5(인과 루프와 마무리)를 모두 구현했다**([33](33.모델-편집기-기반.md)~[38](38.모델-편집기-인과-루프와-마무리.md)). 4차(모델 편집기·보고서)가 끝났다. 이후 보고서 탭 화면 소멸 결함을 고치고 탭별 오류 경계·화면 스모크 시험·사용자 모델 상시 안내를 더했다([39](39.화면-오류-격리와-사용자-모델-안내.md)). 계획 곡선 CSV를 PV로 쓰는 CTL-11은 [40](40.계획-곡선-CSV를-PV로.md), AI 보조 개발 모델 확장의 P0 생성 가속 [41](41.AI-보조-모델-생성-가속.md), P1 검토 부하·오류 탈출 [42](42.AI-보조-모델-검토-부하와-오류-탈출.md), P1b 규모 의존 검출 효율과 후기 발견 비용 [43](43.AI-보조-모델-규모-의존-검출과-후기-발견-비용.md), P2 기술 부채 [44](44.AI-보조-모델-기술-부채.md), P3 계획이 믿는 효과와 실제의 차이 [45](45.AI-보조-모델-계획-오판.md)까지 구현했고, 오류 종류 분리 실험 결과는 [46](46.AI-보조-모델-오류-종류-분리-실험.md)에 있다(분리하지 않기로 유지), P4 비용 층(맨데이를 금액으로 바꾸는 출력 전용 층)은 [47](47.AI-보조-모델-비용-층.md)이다, macOS 설치 파일(`.dmg`·`.zip`) 패키징은 [48](48.데스크톱-앱-패키징.md)이다.
