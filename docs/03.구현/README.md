## 아직 구현하지 않은 설계

2차 범위(시나리오 비교, Earned Value 제어)는 모두 구현했다. 3차의 위험 분석(순서 1~6: 계산·Worker·스토어·화면·파일 저장·E2E)을 모두 구현했다. 모델 검증은 순서 1~7(지표·정렬, 데이터 비교 화면과 파일 저장, 엔진 불변식과 구조 점검 계산, 극단 조건·교란 시험과 화면, 구조 점검 화면·체크리스트·검증 기록, 보정과 프리셋, 전체 E2E)를 모두 구현했다. 4차(모델 편집기 M0~M5, 보고서 R0~R4)도 모두 구현했다. 남은 것은 2차의 후속 항목은 CTL-11(계획 곡선 CSV를 PV로)과 CTL-12(범위 축소 조치)이다. 자세한 것은 `docs/01.분석/02.기능목록.md` 참조.
