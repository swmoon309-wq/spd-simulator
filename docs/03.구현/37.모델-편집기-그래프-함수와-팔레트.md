## 2. 설계와 달라진 것

- **설계 10.1의 둘째 묶음**("3.4 기반 구조 일부(지수 성장·S자 성장, 지연, 균형 피드백, 평활)")은 **중복을 피해** 정리했다: 지수 성장 = 복리 과정, 균형 피드백 = 조정 과정, 1차 지연 = 배출 과정과 같은 구조라 3.3의 템플릿으로 갖고 있고, 3.4에는 새로운 S자 성장·DELAY1·DELAY3·SMOOTH 4종을 두었다.
- **라이브러리 전체 가져오기**를 별도 기능이 아니라 템플릿의 한 묶음으로 했다(Brooks·통합 프로젝트 포함). 접두사를 붙여 병합하는 것은 같다.
- 곡선 모양 템플릿("책의 초과근무 배율 곡선 같은 점 집합")은 책 그림의 수치를 옮기지 않고 **정규화된 일반 모양 5가지**만 둔다(설계도 "형태만, 수치는 사용자 값"이라 했다).
- 점 표의 x를 바꿔 순서가 어긋나면 **자동 정렬**한다(점이 다른 위치로 옮겨 보인다). 차트에서 끌 때는 앞뒤 점을 넘지 못해 순서가 바뀌지 않는다.
- **M2에서 남긴 일을 닫았다**: 테이블의 `xUnit`·`yUnit`을 화면에서 편집할 수 있다. 통합 모델의 인라인 GRAPH 7곳(M2에서 단위 오류 3곳을 이미 표로 옮겼다)도 "모두 테이블로 바꾸기"로 옮길 수 있다.

## 4. 확인하지 못한 것·남긴 것

- **Electron 앱에서 그래프 함수·팔레트를 직접 확인하지 못했다**(브라우저에서만).
- 곡선 차트의 **끌기 동작은 합성 포인터 이벤트로 확인**했다(실제 손으로 끌어 본 것이 아니다). 키보드(방향키) 이동은 구현했으나 브라우저에서 눌러 보지는 않았고 순수 계산(`keyStep`)만 시험했다.
- 곡선의 점 수가 많을 때(100개) 차트와 표의 사용성, 한 화면에서의 표시 크기는 사람이 다듬을 여지가 있다.
- 템플릿의 **출력 포트는 안내만** 한다(삽입 뒤 다른 수식이 그 변수를 쓰게 하면 연결된다). 출력 포트를 선택해 기존 변수의 수식에 자동으로 넣는 기능은 만들지 않았다.
- 템플릿의 기본값·단위(`단위`, `부산물` 같은 일반 이름)는 일반적인 것이라 삽입한 뒤 사용자가 자기 모델의 단위로 바꿔야 한다(단위 검사가 어긋나는 곳을 알려 준다).
- 초안 자동 저장·복구는 여전히 없다.
