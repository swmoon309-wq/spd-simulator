# 위험 분석: 입력과 분포 화면 (설계 06의 순서 4)

설계: [06.위험분석설계.md](../02.설계/06.위험분석설계.md) 5.1~5.2, 7장(RSK-01~03). 앞 단계(Worker·스토어)는 [11](11.위험분석-Worker와-스토어.md).

## 1. 구현한 것

새 탭 **위험 분석**(실험 / 시나리오 / 통제 / 위험 분석)에서 입력 → 실행 → 분포 확인까지 한 흐름이 동작한다.

| 영역 | 내용 | 파일 |
|---|---|---|
| 불확실한 입력 | 파라미터를 골라 더하면 삼각(0.8배/1배/1.3배) 분포가 들어간다. 종류(균등·삼각·PERT·정규)와 값을 고칠 수 있고, 올바르지 않으면 바로 아래에 이유를 보인다. 최대 12개, 실행 중에는 잠긴다 | `components/risk/InputList.tsx`, `DistributionEditor.tsx` |
| 실행 줄 | 대상(기준 또는 시나리오), 반복 수, 시드, 시간 변화 변수, 실행·중단, 진행 막대, 상태 글. 실행할 수 없으면 이유를 보인다(다른 실행 중, 입력 오류, 검사 실패) | `RiskRunBar.tsx` |
| 결과 | 지표 선택, 히스토그램(구간 수 조절), 신뢰 수준 차트(P50·P80·P90 점선), P50·P80·P90과 95% 구간, 여유(P80−P50), 요약 통계 표, 히스토그램 값 표, 시간 변화 띠(P10~P90, 중앙값). 실행 중에는 중간 결과를 보인다 | `RiskResults.tsx`, `DistributionCharts.tsx`, `BandChart.tsx` |
| 화면 자료 | 분포 종류 전환, 입력칸 정의, 히스토그램·누적분포·분위수·상태 글을 만드는 순수 함수 | `lib/riskView.ts` |

상시 안내(입력 분포는 가정, 모델은 보정되지 않음, 상대 비교 우선)를 결과 아래에 항상 보인다(설계 0장).

## 2. 동작 규칙

- **오래됨**: 입력·시드·대상·실행 설정이 바뀌면 상태 글에 "결과가 오래되었습니다"가 붙고 결과를 흐리게 보인다. 기존 `selectRiskStale`을 쓴다.
- **미완료 반복**: 지표를 정할 수 없는 반복은 분포에서 빼고 비율로 따로 보인다("정할 수 있는 N회만의 분포"). 수치 오류로 제외한 반복도 따로 센다.
- **거친 분포**: 반복이 100회 미만이면 경고를 보인다.
- **종류 전환**: 이전 분포의 범위와 최빈값을 이어받고(균등·정규에서 오면 평균), 허용 범위로 맞춘다. 정수 파라미터는 반올림한다. 정규로 바꿀 때 표준편차는 (최대−최소)/4이다.
- **누적분포 점**: 표본이 200개를 넘으면 줄여서 그린다(끝점은 항상 1).
- **접근성**: 차트에 요약 `aria-label`을 달고, 같은 값을 표로 함께 낸다.

## 3. 설계와 다른 점, 아직 없는 것

- 결과 탭 **[분포][목표][민감도][수렴][비교]** 중 지금은 분포만 있어 탭 막대를 두지 않았다(빈 탭을 만들지 않기 위함). 나머지는 순서 5.
- 시계열 띠에 **기준(결정적) 실행의 곡선**은 겹치지 않았다.
- **내보내기(CSV)** 는 없다.
- 입력 목록의 템플릿 선택 대신 "추가하면 삼각 템플릿"으로 단순화했다(설계의 템플릿 버튼과 동작은 같다).
- 설정은 아직 파일에 저장하지 않는다(순서 6).

## 4. 시험

`lib/riskView.test.ts` 11개(desktop 581 → 592): 분포 종류별 입력칸, 값 하나만 바꾼 새 분포, 종류 전환(범위 이어받기·허용 범위 제한·정수 반올림, 삼각↔PERT에서 최빈값 유지), 한 줄 요약, 히스토그램 도수 합 = 지표가 있는 반복 수와 비율 합 1, 구간 수 지정·제한, 누적분포 증가·끝 1·점 줄이기, 분위수 오름차순과 구간 포함, 상태 글.

화면은 개발 서버(renderer 전용)의 브라우저에서 확인했다: Brooks 모델, 공칭 생산성에 삼각 분포, 500회 실행으로 히스토그램·신뢰 수준 차트·P50 268.1일·P80 289.7일(95% 구간)·요약 표가 나오고, 시드를 바꾸면 "오래되었습니다"가 뜨며, 시간 변화 변수(누적 투입 공수)를 고르면 띠가 그려진다. 콘솔 오류는 없었다. Electron 앱에서의 E2E는 순서 6에서 한다.

## 5. 관찰

- 개발 서버(renderer 전용)는 Electron 없이도 Worker 실행이 되어 화면 점검에 충분했다. 파일 저장·열기는 Electron에서만 된다.
