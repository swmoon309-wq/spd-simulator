## 1. 구현

보고서 탭에 **PDF로 저장…** 버튼이 있다. renderer는 PDF를 만들지 않고 HTML 문자열을 main에 보낸다(경로·권한은 main만 안다).

| 구성 | 내용 | 코드 |
|---|---|---|
| `ReportService.exportPdf` | ① 크기 확인(20 MB 초과면 대화상자도 열지 않고 거절) ② **저장 위치 선택**(취소하면 창도 임시 파일도 만들지 않는다) ③ 임시 HTML 파일(`userData/tmp`) ④ 숨은 창에서 `printToPDF` ⑤ 임시 파일에 쓴 뒤 이름 바꿔 저장 ⑥ **창과 임시 파일은 실패해도 항상 정리** | `main/reportService.ts` (Electron에 의존하지 않음: 창·파일·대화상자를 주입) |
| 숨은 창 | `createPdfWindow`: `sandbox`·`contextIsolation`, 노드 없음, **JavaScript 끔**, `webSecurity`, **영속하지 않는 별도 파티션**(앱 기본 세션을 건드리지 않음), 새 창 거부, 이동 차단, **`file:`와 `data:` 외의 모든 요청을 취소** | `main/pdfWindow.ts`, `pdfWindowPreferences`, `isAllowedRequestUrl` |
| PDF 옵션 | A4, 배경 인쇄, **쪽 번호 꼬리말**(`n / 전체`), 문서의 `@page` 크기·여백 사용, **문서 개요(북마크)**와 **태그 PDF**(제목·표·그림의 구조, 접근성) | `pdfOptions()` |
| IPC | `report:exportPdf`(내용 최대 20 MB를 main에서도 검증), preload `report.exportPdf` | `shared/ipc.ts`, `main/ipc.ts`, `preload/index.ts` |

**실제 Electron에서 확인해 고친 것**
- **문서 개요가 처음에는 만들어지지 않았다.** `generateDocumentOutline`만 켜면 개요가 나오지 않았고, `generateTaggedPDF`를 함께 켜자 `/Outlines`가 생겼다(두 옵션을 함께 쓴다).
- **좁은 칸**: 비교표의 값·차이가 한 줄에 몰려 값과 단위가 갈라졌다. 값과 차이를 **두 줄**로 나누고(칸 안의 줄바꿈이 보이도록 `white-space: pre-line`, 읽을 때 절의 목록 콜아웃도 줄이 살아난다) 값과 단위 사이는 **줄바꿈하지 않는 공백**으로 이었다.
- 숨은 창만 있는 시험 앱은 창이 닫히면 끝나 버렸다(실제 앱에는 주 창이 있어 영향이 없다).

## 2. 시험

전체: analysis 564, models 229, engine 193, desktop 1,160(+11) 통과. 타입 검사·`npm run build` 통과.

- `main/reportService.test.ts` 11개(가짜 창·실제 임시 폴더): 파일 이름 규칙, PDF 옵션, **창 보안 설정(스크립트 끔·샌드박스·별도 파티션이 `persist:`가 아님)**, 허용 주소(`file:`·`data:`만, `https:`·`javascript:`·`blob:` 등 거절), 저장 경로·확장자 보정, 창이 받은 HTML이 그대로임, 끝나면 창 닫기·임시 파일 삭제, **취소하면 아무것도 만들지 않음**, 20 MB 거절, 불러오기·인쇄·쓰기 실패 각각에서 이유 알림과 정리(반쯤 쓴 PDF가 남지 않음).
- **실제 Electron으로 PDF 생성**(시험 앱을 번들해 실행, 저장소 밖 임시 폴더): 통합 모델 예제의 시나리오 비교 보고서 **7쪽**, 계획서 요약 **4쪽**, 모두 A4(594.96×841.92 pt), 쪽 번호 `3 / 7`, 제목(문서 정보), **개요(북마크)와 태그 PDF**, 차트는 벡터, 표·그림이 쪽 중간에서 끊기지 않음(쪽 이미지로 확인), 텍스트 추출로 핵심 문구(완료일, ▲▼ 판정, 읽을 때 절) 확인.
- **적대적 문서**: 외부 스타일시트·이미지·iframe·`fetch`를 부르고 본문을 바꾸는 스크립트가 든 HTML을 같은 서비스로 PDF로 만들었다. **스크립트가 실행되지 않았고(`SCRIPT-RAN` 없음) 로컬 서버가 받은 요청이 0건**이었다. 제목에 `<b>굵게</b>`가 든 프로젝트 이름은 글자 그대로 나왔다.
- **Electron 앱**: 보고서 탭에서 `HTML로 저장…`·`PDF로 저장…` 버튼이 활성이고 새 API가 노출되며 미리보기와 절 목록이 나온다.

## 3. 확인하지 못한 것

- 저장 대화상자는 시스템 UI라 앱 안에서 눌러 보지 못했다. 서비스는 대화상자를 주입받아 시험했고, 대화상자 부분(`dialog.showSaveDialog`)은 다른 저장 기능과 같은 방식이다.
- 막대 차트에서 기준선 라벨("기준")이 가로 축 숫자와 겹치는 경우가 있다(화면 차트와 같은 옵션). 보고서용으로 다듬는 것은 후속이다.
