## 2. R1 계획서 요약과 시나리오 비교

### 2.1 빌더 (`lib/report/build.ts`, `sections.ts`)

`buildReport(state, options) → { doc, sections }`: 종류마다 절 구성이 정해져 있고 절마다 자료 상태를 판단한다.

| 종류 | 절 |
|---|---|
| 계획서 요약 | 개요 · 입력 · 기준 실행 결과 · 채택 계획 · 시나리오 · **읽을 때** · **만든 조건** |
| 시나리오 비교 | 개요 · 시나리오 목록과 기준과 다른 값 · 지표 비교 · 차트 · 채택 계획 · **읽을 때** · **만든 조건** |

- **기준 실행은 현재 입력으로 그 자리에서 계산한다**(몇 ms). 그래서 계획서 요약의 숫자는 항상 최신이고 재현된다. 시나리오 결과는 세션의 일괄 실행 결과를 쓴다.
- **입력 절**: 그룹별 표(항목·값·기본값), 기본값과 다른 값은 굵게 표시하고 개수와 이름을 알린다. **개요**: 핵심 지표(일정·공수·결함 그룹의 첫 지표)를 한 문단으로.
- **채택 계획 절**: 채택 시나리오·시각·계획·개정 횟수, **채택한 뒤 바뀐 입력**이 있으면 경고와 표(채택 시/지금). 채택이 없으면 해당 없음.
- **비교표**: 그룹별 표. 시나리오 칸은 값과 기준 대비 차이를 **화살표(▲▼＝)와 판정 글자(좋음·나쁨)와 변화율**로 함께 싣는다(색에만 의존하지 않는다, 흑백 인쇄). 값은 화면의 포맷터(`formatValue`·`formatDelta`)를 그대로 쓴다.
- **차트**: 일정·비용·품질 그룹의 첫 지표 막대, 축이 3개 이상이면 레이더(Brooks는 축이 둘이라 없음, 통합 모델은 있음), 기본 변수의 실행 겹쳐 보기. **모든 차트에 같은 값을 담은 표(또는 대체 문장)가 함께 간다.**
- **읽을 때**(끌 수 없음): 고정 문구 3개(결과는 예측이 아니라 추정, 보증하지 않음·합격 판정 없음, 재현성) + **모델별 문구**(Brooks는 책 수치와 일치 확인, 통합 모델은 보정되지 않음·가정한 값 있음, 구조 모델은 학습용·기본값은 보정값이 아님) + 이 보고서에서 **최신이 아니거나 빠진 절의 목록**(싣지 않았는지 포함).
- **만든 조건**(끌 수 없음): 앱 버전, 모델 id·버전, 실행 설정, 시나리오 수, 채택 계획, 만든 시각.

### 2.2 신선도 규칙 (설계 09의 4.1)

- 절 기본값은 **최신인 절만 켜짐**(오래됨·없음·해당 없음은 꺼짐). 비교·차트의 판단: 모든 열이 최신이면 `fresh`, 결과가 하나도 없으면 `missing`, 그 밖(일부 없음·오래됨)은 `stale`이고 이유(`입력이 바뀌어 오래된 결과: …`, `아직 실행하지 않음: …`)를 적는다.
- **오래된 결과는 숫자를 싣지 않는다**: 사용자가 절을 켜도 "숫자를 싣지 않았습니다"와 이유만 나간다. **"오래된 결과 포함"**을 켜야 숫자를 싣고, 그때는 절 머리의 경고 콜아웃과 열 이름의 "(오래됨)" 표시가 붙는다. 시나리오가 직접 정한 값은 기준이 바뀌어도 그대로라 그 시나리오의 결과는 최신으로 남는다(시험으로 확인).

### 2.3 화면과 저장 (`components/report/ReportTab.tsx`)

새 탭 **보고서**(Cmd/Ctrl+7).

- 종류·제목(비우면 "<프로젝트> — <종류>")·작성자, **절 체크박스와 상태 뱃지·이유**(끌 수 없는 절은 "항상 포함"), "오래된 결과 포함", 차트 크기, **필요한 결과 만들기**(시나리오의 없거나 오래된 결과를 일괄 실행. 위험 분석·상태는 R3), **HTML로 저장…**.
- **미리보기**: `<iframe sandbox="" srcDoc>`(스크립트·폼·팝업 없음, 문서에 접근할 수 없음을 브라우저에서 확인). **화면 / A4** 폭 전환. 내보내는 파일과 같은 문자열이다. 제목을 치는 동안 차트를 매번 다시 그리지 않게 250 ms 기다린다.
- **HTML 저장**: 새 IPC `file:exportHtml`(`TextFileService.exportHtml`, `.html` 보장, 경로 문자 치환, **20 MB 상한**, 임시 파일 후 이름 바꾸기). 데스크톱 앱에서만(브라우저에서는 비활성).
- 설정은 아직 화면 상태(`stores/reportStore.ts`)로만 둔다. 프로젝트 파일에 저장하는 것은 R4(RPT-07).
- **메뉴**: 보고서 메뉴가 활성화되어 "보고서 만들기…"(탭 열기)와 종류별 항목(`report:plan`, `report:scenarios`)이 있다. 탭 이동 단축키에 Cmd/Ctrl+7 추가.
